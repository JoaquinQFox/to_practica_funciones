
# Práctica 07: Sistema de Productos

## Curso
Tecnología de Objetos

## Objetivo
Desarrollar un sistema de productos en C++ que integre
los conceptos de funciones inline, funciones friend,
funciones const, expresiones lambda y sobrecarga
de operadores.

## Requisitos del sistema

1. Implementar una función inline para calcular descuentos.
2. Crear una clase Producto con atributos privados.
3. Implementar una función friend para comparar precios.
4. Utilizar funciones const para consultar datos.
5. Aplicar expresiones lambda para filtrar productos.
6. Sobrecargar el operador + para combinar productos.
7. Sobrecargar el operador << para mostrar productos.

## Organización del código

- Producto.h: declaración de la clase Producto.
- Producto.cpp: implementación de sus métodos.
- Descuento.h: función inline para descuentos.
- main.cpp: integración y pruebas del sistema.

## Compilación y ejecución

Las instrucciones definitivas de compilación se
incorporarán cuando estén integrados los archivos
de todos los integrantes.
